## Product details

**Name**

Copy Gmail Thread for AI

**Summary**

Copy or export complete Gmail threads as AI-ready text for ChatGPT, Claude, or
Gemini. Private, local, and no account.

Productivity — use the closest available subcategory to Workflow & Planning.

**Language**

## Detailed description

**DATA HANDLING DISCLOSURE:** When you activate a copy action, this extension
reads the Gmail conversation already open in your browser—including message
contents, names and email addresses, dates, links, and attachment information—
and processes it locally solely to create the output you requested. It does not
send this data to Zena Labs or third parties, and the extension does not retain
it. Choosing to install and use a copy action is your affirmative consent to
this disclosed handling.

Copy or export a complete Gmail email thread as structured, AI-ready text you
can paste into ChatGPT, Claude, Gemini, Copilot, or another assistant. Preserve
the context ordinary copy and paste can miss: collapsed messages, senders,
recipients, timestamps, links, tables, signatures, and attachment information.

Use the full conversation to summarize a long email thread, draft a reply,
extract action items and decisions, review a negotiation, prepare a handoff, or
give an AI assistant reliable context without granting it access to your Gmail
account.

WHY IT IS DIFFERENT

- Requests Gmail's full conversation print view, including messages that may be
  collapsed on the visible page.
- Verifies that Gmail returned the same conversation you opened before anything
  is copied.
- Keeps every message clearly attributed to its sender, recipients, and date.
- Marks partial or uncertain captures with explicit completeness warnings
  instead of silently presenting missing content as complete.
- Records attachment context per message and can optionally save verified files
  with a copy of the structured thread.
- Identifies possible unsent drafts so their text is not mistaken for something
  a participant actually communicated.
- Processes locally with no extension account, Google OAuth flow, API key,
  analytics, advertising, or publisher server.

Features:

- Copy complete email conversations as strict XML with readable Markdown message
  bodies.
- Preserve who said what, when, and to whom, including Cc and Bcc where Gmail
  provides them.
- Keep useful links, lists, tables, signature blocks, and message boundaries.
- Attribute attachments to individual messages where Gmail exposes enough
  information.
- Optionally save verified attachments and `thread.xml` in a thread-specific
  folder under Chrome's configured download directory.
- Remove recognized duplicate quoted history while retaining uncertain inline
  replies.
- Surface field-specific, machine-readable completeness warnings.
- Use popup controls, in-page controls, or configurable keyboard shortcuts.

HOW IT WORKS

1. Open one conversation in Gmail.
2. Choose **Copy thread** or **Copy + save files**.
3. Paste the structured conversation into the AI or document tool you choose.

The extension does not summarize, rewrite, or send email itself. It prepares a
complete, reviewable context document and leaves you in control of where that
document goes.

Privacy by design:

- No transfer to Zena Labs, an AI provider, analytics service, or advertiser;
  the only network origin is Gmail itself.
- No analytics, telemetry, advertising, tracking, OAuth, API key, or extension
  account.
- No persistent storage of messages or account information.
- No remote code.
- Gmail-only host access.

The extension does not automatically send email to ChatGPT, Claude, or another
AI service. Data leaves the browser only when you separately paste, upload, or
otherwise send it to a destination you choose. Review the thread for private or
regulated information before doing so.

Reliability notice: Gmail's interface is undocumented and can change.
Review every capture and warning before sharing or relying on it. This is not a
system of record, e-discovery tool, compliance system, security product, or
professional service. It is provided as-is without warranties; see the Terms
of Use for details.
