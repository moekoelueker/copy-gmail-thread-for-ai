# Support

Copy Gmail Thread for AI is a Developer Preview maintained by Zena Labs LLC.
It is provided without a service-level agreement or guaranteed response time.

## Get help or report a problem

- Public issue tracker:
  <https://github.com/moekoelueker/copy-gmail-thread-for-ai/issues>
- Contact: <zenalabsllc@gmail.com>
- Manual test checklist: [docs/manual-test.md](docs/manual-test.md)

Before reporting a problem, reload the Gmail tab, confirm that a conversation
is open, and retry. Include the Chrome version, operating system, extension
version, the action attempted, the warning or error text, and reproducible
steps.

## Do not submit private email data

The public issue tracker is visible to everyone. Do not post real message text,
names, email addresses, attachment contents, Gmail URLs, account identifiers,
authentication information, or other confidential data. Reproduce the problem
with synthetic content or redact it first. If a specific private sample is
strictly necessary, contact Zena Labs LLC before sending anything.

## Security reports

Do not publish an exploitable security vulnerability or private user data in a
public issue. Email <zenalabsllc@gmail.com> with the subject
`Security report: Copy Gmail Thread for AI` and provide the minimum information
needed to reproduce the issue. Do not include real email contents unless Zena
Labs LLC specifically requests a redacted sample after reviewing the report.

## Current support boundaries

- Chrome on macOS has received the most testing.
- Chrome on Windows is intended to work but still needs a documented live pass.
- Other Chromium browsers, mobile browsers, and non-Gmail mail services are not
  currently supported.
- Gmail interface changes can temporarily break capture even when the extension
  package itself has not changed.
