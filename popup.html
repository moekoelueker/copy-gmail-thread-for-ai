Copy Gmail Thread for AI

Data handling. When you choose a copy action, this extension reads the open Gmail conversation—including message text, participant details, links, and attachment information—and processes it locally to create your output. It does not send or retain that data.

Uses this signed-in Gmail tab. No Google sign-in or extension account. Saved files go to Chrome’s download directory.

Developer Preview. Built for personal productivity. Review copied output before sharing or relying on it.

This works inside Gmail. Open an email thread at mail.google.com, then use the shortcut or this popup.
